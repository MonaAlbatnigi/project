# Project

A clean, modern, and minimal agency website template built using **HTML5** and **CSS3**
---
## 🧩 Features & Sections
The template is divided into seven main sections[cite: 1]:
1. **Header & Navigation:** Includes the brand logo and an interactive hover-triggered dropdown navigation menu for quick access to page sections
2. **Landing (Hero Section):** Full-viewport background banner with a centered introductory heading and tagline
3. **Features:** A 3-column highlight section showcasing core agency strengths with Font Awesome icons
4. **Services:** Displays offered services (*Graphic Design*, *UI & UX*, *Web Design*, and *Web Development*) alongside a featured service image
5. **Portfolio:** A showcase gallery highlighting recent projects with thumbnails and descriptions
6. **About:** Agency background section paired with visual imagery and structured text
7. **Contact:** Direct email contact link (`leon@gmail.com`) and social media links (Google, Facebook, X/Twitter)

## 🛠️ Technologies Used
* **HTML5:** Semantic structure (`<header>`, `<div id="...">`, clean sectioning)[cite: 1].
* **CSS3:** 
  * Custom CSS Variables (`--main-color`, `--secondary-color`, `--section-background`) for consistent theming[cite: 2].
  * Flexbox layout and positioning (`position: relative/absolute`, `transform`)[cite: 2].
  * Smooth scrolling behavior (`scroll-behavior: smooth`)[cite: 2].
  * Hover transitions and interactive dropdown menus[cite: 2].
* **Google Fonts:** *Work Sans*, *Ubuntu*, and *Oswald*[cite: 1].
* **Font Awesome:** Vector icons for UI elements, features, and social links[cite: 1].
